Starbie
A tiny motion-controlled digital pet, basically a desktop Tamagotchi.
Project Overview
This project outlines the process of building a simple 2-key Starbie equipped with an MPU6050 motion sensor and a DHT11 Environment sensor. The development is split into two main stages: PCB Design and Firmware development.

Development Process
1. PCB Design
Using KiCad for the open-source PCB design phase:
 * Drawing the schematic.
 * Creating the PCB Layout.
 * Exporting the final design deliverables.
2. Firmware Implementation
Developing the pet’s behavior and sensor integration.
